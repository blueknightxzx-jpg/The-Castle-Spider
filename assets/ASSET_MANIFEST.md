# Generated Asset Integration

These are crops/derived exports from the already-generated Castle Spider artwork in this chat.

## Player
- `assets/player_spider/knight_spider_idle_atlas.png`
- 4 knight idle directions occupy row 1, cells 0–3:
  - 0: down
  - 1: left
  - 2: right
  - 3: up

## Spider
- Same atlas, row 2, cells 0–3:
  - 0: down
  - 1: left
  - 2: right
  - 3: up

Each cell is 64×64px. The knight occupies a 48×64 transparent sprite centered inside its 64×64 cell; spider cells are 64×64.

## Castle map
- `assets/map/castle_map_asset_atlas.webp`
- Reduced reference atlas extracted from the already-generated castle/map sheet.
- Contains the castle layout, map-scale reference, floors, walls, structural elements, closets, golden exit and room examples.

No new artwork was generated for these repository assets; they are derived from the existing generated sheets.
