# The Castle Spider — v0.4
## INTERACTION SYSTEM

v0.4 implements the interaction layer already reserved by the locked roadmap.

### Scope
- E is now an active interaction key.
- The player detects a nearby interactive closet.
- A contextual E prompt appears only within interaction range.
- Pressing E toggles a closet between closed and open.
- Closet doors animate smoothly.
- Interaction stays lightweight and world-object based.

### Closet boundary
The enlarged closets remain future hiding locations, but hiding is **not** part of v0.4.

v0.4 establishes:
**Approach → prompt → E → interact → visual response**

Hiding remains scheduled for **v0.6**.

### Sprint/recovery UI
The sprint system now has:
- smooth visual stamina refueling
- a one-shot exhaustion warning per exhaustion event
- no repeated warning loop while Shift is held

### Performance
- Nearby objects only are considered for the active prompt.
- Door animation uses simple interpolation.
- No new heavy rendering dependency is introduced.
- Existing low-spec performance constraints remain active.
