# The Castle Spider — v0.3
## CASTLE — WORLD-SCALE REBUILD

### Goal
Create the full-map side-view castle hallway as a structured, visually coherent space that can support later interaction, hiding and horror systems.

### Full map
- Total map length: **1,200 meters**
- Rendering scale: 4 pixels per meter
- World width: 4,800 px
- One continuous horizontal traversal space
- Five 240m architectural sections using one alignment system

### Systems
- Full castle world data
- Long horizontal traversal
- World-sized camera travel
- Structured architecture grid
- Windows
- Columns
- Wall sconces
- Visually distinct closets
- Single grand main exit
- Player integrated into hallway

### Closets
- Closets are the only current cabinet/door-like hiding structures.
- Closet positions sit on a 30m grid.
- Closet gaps are varied but constrained to **90–120m**.
- Placement avoids structural columns.
- Closet height is aligned directly beneath the window line, creating clean wall composition.
- Placement metadata can later carry hiding/safety behavior.
- Closets are visual-only until v0.4+ activates interaction.

### Exit
- The castle ends at one grand main exit.
- The exit is a large golden double door with a stone arch and ornate panels.
- No textual exit label is used.

### Visual rules
- No room names are rendered into the world.
- No section labels are rendered.
- No "North Exit" text exists.
- Structural bays, floor baselines, columns and major wall fixtures remain aligned.
- Decorative pieces must not overlap structural pillars.
- Closet fronts align to the same floor baseline as the player.

### Acceptance criteria
1. Player traverses a 1,200m hallway.
2. A/D and Left/Right are the only movement controls.
3. W/S/Up/Down do not move the player.
4. Closets are the only current door-like cabinet objects.
5. Closet gaps are 90–120m and deterministic.
6. The final exit is a single grand golden door.
7. No room or exit labels are drawn.
8. Major architecture remains aligned.
9. Default character is used.
