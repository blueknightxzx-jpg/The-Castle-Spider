# The Castle Spider — v0.1
## TECHNICAL FOUNDATION

### Goal
Establish a clean, testable foundation that later gameplay systems can build on without a rewrite.

### Included
- Application startup
- Game loop
- Delta-time limiting
- Scene/state management
- Keyboard input abstraction
- Canvas renderer
- Responsive scaling
- Camera foundation
- Debug overlay
- Separate content scenes

### Proof
The foundation sandbox uses a moving marker to verify real-time input, updates, rendering, and state transitions. It is deliberately not gameplay.

### Performance decisions
- Internal resolution: 960x540
- Device pixel ratio capped at 1.5
- Canvas 2D renderer
- Maximum simulation delta: 1/30 second
- No per-frame DOM animation
- No external runtime dependencies

### Exit criteria
Before v0.2:
1. Game boots reliably.
2. Scene switching works.
3. Keyboard input works.
4. Renderer scales correctly.
5. Camera foundation exists.
6. Old prototype is no longer the active runtime.
7. Performance baseline is documented.
